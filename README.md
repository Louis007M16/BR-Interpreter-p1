# BR-Interpreter-p1
Making an interpreter using java programming language, that will execute basic programming language basic operations, variable declaration and  if-else statement. (No functions or Class yet).
# Syntax and Features
# Comments
```br
npc# This is a comment.
```
# Variable
```br
spawn number = 10
spawn bool = W or L
spawn string = "Hello"
```
# Input & Output
**flex()**
```br
flex("Hello World!\n")  npc# Outputs `Hello World!` to the console
```
**rizz()**
```br
spawn input = rizz()  npc# Parses input from user as a string
```
**If-else Statements**
```br
alpha condition
  npc# body
omega
  npc# body
slay
```
**Else if Statements**
```br
alpha condition
  npc# body
beta condition
  npc# body
omega
  npc# body
slay
```
# Looping
**While loop**
```br
grind condition
  npc# body
slay
```
**For loop**
```br
yap NAME in start~end
  npc# body
slay
```
# Switch
vibe_check expr
  its_giving value

# Break / Continue
selling     npc# break
bounce      npc# continue
